# رَحّالَة (Rahhala) — مركز الدفعة الدراسي

منصة ويب عربية (RTL) كاملة ومصممة للعمل على الجوال وسطح المكتب لتنظيم المواد الدراسية، مناقشات الدفعة، الإعلانات، إدارة الأعضاء، ومجالس المذاكرة الجماعية.

---

## ١. التشغيل المحلي والإعداد

```bash
npm install
npm run dev
```

يعمل الخادم الموحّد (Express + WebSocket + Vite) على المنفذ `3000`.

### تهيئة حساب المالك (Owner) في الإنتاج
لا يوجد تسجيل عام لحساب المالك ولا توجد كلمات مرور افتراضية ثابتة في الكود. لإنشاء حساب المالك من سطر الأوامر:

```bash
npm run init-owner -- --username owner_handle --name "الاسم الكامل" --email owner@example.edu --password "كلمة_مرور_قوية"
```

أو عبر متغيرات البيئة: `RAHHALA_OWNER_USERNAME` و `RAHHALA_OWNER_NAME` و `RAHHALA_OWNER_EMAIL` و `RAHHALA_OWNER_PASSWORD`.

### وضع المعاينة المحلية التجريبية (التطوير فقط)
عند التشغيل في وضع التطوير (`NODE_ENV !== 'production'` و `RAHHALA_PREVIEW_DEMO !== 'false'`) وفي حال عدم وجود مستخدمين بعد، يتم توليد بيانات تجريبية وهمية بكلمات مرور عشوائية في قاعدة البيانات المحلية، مع إتاحة بطاقة معاينة سريعة على شاشة الدخول فقط (تُعطل تلقائيًا في الإنتاج).

## ٢. البنية والبيانات (Data Model)

تعتمد المنصة على SQLite مع ترحيلات مهيكلة (`server/db.ts`) وتفعيل القيود المرجعية (`PRAGMA foreign_keys = ON`):
- **users / sessions / auth_attempts**: الحسابات (عضو / مشرف / مالك)، الجلسات المقيدة بالخمول لمدة ساعتين (مع استثناء الاستطلاع الخلفي من تمديد الجلسة)، وحدود المحاولات الفاشلة (قفل ١٠ دقائق بعد ٨ محاولات).
- **subjects / sections / materials**: المواد الدراسية وأقسامها وروابط المصادر مع ترتيب حتمي وتنظيف آمن عند الحذف.
- **messages / message_hides / reactions / channel_reads / receipts / typing_states**: قنوات المحادثة الثلاث (`إعلانات`، `أسئلة`، `عام`) مع قواعد الحذف (٤٨ ساعة للجميع، وحذف نهائي للمالك فقط) وتفاصيل القراءة.
- **history_requests**: صلاحية منفصلة للوصول إلى الرسائل القديمة للأعضاء الجدد.
- **assets / asset_chunks**: تخزين وتحقق من التوقيع الثنائي الفعلي للملفات (صور، PDF، صوت، DOCX/PPTX/XLSX) عبر أجزاء محققة الطول والبصمة، مع روابط وصول قصيرة الأجل.
- **app_settings / admin_audits**: إعدادات الهوية ومجلس المذاكرة وقفل المحادثة وسجل تدقيق إداري آمن.

---

## ٣. قواعد الأدوار والصلاحيات

- **العضو (member)**: تصفح المواد، المشاركة في قناتي `أسئلة` و`عام` عند فتح المحادثة، قراءة `إعلانات` فقط، حذف رسائله عند الكل خلال ٤٨ ساعة فقط، وطلب الوصول للرسائل القديمة.
- **المشرف (admin)**: كل صلاحيات العضو + نشر الإعلانات، قفل/فتح المحادثة، قبول/رفض طلبات الانضمام وطلبات الرسائل القديمة، إدارة المواد والأقسام، ترقية/خفض الأعضاء غير المالك، تعديل البريد السري وإعادة تعيين كلمة مرور الأعضاء العاديين وإزالتهم. لا يمكنه المساس بالمالك أو إزالة مشرف آخر.
- **المالك (owner)**: حساب محمي لا يمكن حذفه أو تغييره أو إعادة تعيين كلمة مروره من أي حساب آخر، ويمتلك وحدَه صلاحية إزالة المشرفين أو إعادة تعيين كلمات مرورهم، والحذف النهائي للرسائل، وتصدير أرشيف الكود المنقّى.

---

## ٤. التكاملات الاختيارية

- **مجلس المذاكرة (Majalis)**: يعمل افتراضيًا بغرفة صوت وصورة مدمجة عبر WebRTC وإشارات WebSocket من نفس الخادم دون الحاجة لخدمة خارجية، ويمكن للمشرف أو المالك ضبط رابط مزود اجتماعات خارجي مخصص من تبويب **الإدارة ← إعدادات المنصة ومجلس المذاكرة** أو عبر `RAHHALA_MEETING_PROVIDER_URL`.
- **استعادة كلمة المرور عبر البريد**: غير مفعّلة افتراضيًا لعدم وجود خادم بريد مهيأ؛ وتعتمد المنصة المسار النشط الموضح للمستخدم: التواصل مع المشرف لتعيين كلمة مرور مؤقتة.
