# رَحّالَة (Rahhala) — مركز الدفعة الدراسي المفتوح المصدر

منصة ويب عربية (RTL) مفتوحة المصدر ومصممة للعمل على الجوال وسطح المكتب لتنظيم المواد الدراسية، مناقشات الدفعة بأسلوب قريب من واتساب، الإعلانات، لوحة الإنجاز وأوقات الذروة، التحديات الجماعية، ومجالس المذاكرة الصوتية والمرئية.

---

## ١. التشغيل المحلي والإعداد

```bash
npm install
cp .env.example .env
npm run dev
```

يعمل الخادم الموحّد (`Express` + `WebSocket /ws` + `Vite`) على المنفذ `3000`.

### تهيئة حساب المالك (Owner) في الإنتاج
لا يوجد تسجيل عام لحساب المالك ولا توجد كلمات مرور افتراضية ثابتة في الكود. لإنشاء حساب المالك من سطر الأوامر:

```bash
npm run init-owner -- --username owner_handle --name "الاسم الكامل" --email owner@example.edu --password "كلمة_مرور_قوية"
```

أو عبر متغيرات البيئة: `RAHHALA_OWNER_USERNAME` و `RAHHALA_OWNER_NAME` و `RAHHALA_OWNER_EMAIL` و `RAHHALA_OWNER_PASSWORD`.

### حفظ قاعدة البيانات (SQLite) في الإنتاج و Cloud Run
تُحفظ جميع البيانات والملفات المرفقة محليًا في ملف SQLite المحدد عبر `RAHHALA_DB_PATH` (الافتراضي `./data/rahhala.db`):
- عند النشر على **Cloud Run** أو أي حاوية سحابية، احرص على ربط **Persistent Volume** (مثل Cloud Storage FUSE Volume أو قرص دائم) على مسار مثل `/mnt/data` وضبط `RAHHALA_DB_PATH=/mnt/data/rahhala.db` حتى لا تُفقد البيانات عند إعادة تشغيل الحاوية.
- في وضع التطوير المحلي، يمكنك تصفح القاعدة عبر `sqlite3 ./data/rahhala.db` أو أدوات SQLite القياسية (يتم تجاهل ملفات `data/` و `*.db*` تلقائيًا في `.gitignore` قبل الرفع على GitHub).

### وضع المعاينة المحلية التجريبية (التطوير فقط)
عند التشغيل في وضع التطوير (`NODE_ENV !== 'production'` و `RAHHALA_PREVIEW_DEMO !== 'false'`) وفي حال عدم وجود مستخدمين بعد، يتم توليد بيانات تجريبية وهمية بكلمات مرور عشوائية في قاعدة البيانات المحلية، مع إتاحة بطاقة معاينة سريعة على شاشة الدخول فقط (تُعطل تلقائيًا في الإنتاج).

## ٢. البنية والبيانات (Data Model)

تعتمد المنصة على SQLite مع ترحيلات مهيكلة (`server/db.ts`) وتفعيل القيود المرجعية (`PRAGMA foreign_keys = ON`):
- **users / sessions / auth_attempts**: الحسابات (عضو / مشرف / مالك)، الجلسات المقيدة بالخمول لمدة ساعتين (مع استثناء الاستطلاع الخلفي من تمديد الجلسة)، وحدود المحاولات الفاشلة (قفل ١٠ دقائق بعد ٨ محاولات).
- **subjects / sections / materials**: المواد الدراسية وأقسامها وروابط المصادر مع ترتيب حتمي وتنظيف آمن عند الحذف.
- **messages / message_hides / reactions / channel_reads / receipts / typing_states**: قنوات المحادثة الثلاث (`إعلانات`، `أسئلة`، `عام`) مع دعم الرد والتعديل والتمييز بنجمة والتثبيت في القناة.
- **user_chat_settings / starred_messages / muted_chat_members**: إعدادات المحادثة الشخصية بأسلوب واتساب (خلفيات المحادثة، حجم الخط، Enter للإرسال، مؤشرات القراءة، أصوات المحادثة، الرسائل المميزة بنجمة، مسح الدردشة عندي، وتصدير المحادثة `.txt`)، وإعدادات الجروب (الاسم، الوصف، القوانين، القفل، السماح بالوسائط والتفاعلات، الرسائل ذاتية الاختفاء، وكتم الأعضاء).
- **history_requests**: صلاحية منفصلة للوصول إلى الرسائل القديمة للأعضاء الجدد.
- **assets / asset_chunks**: تخزين وتحقق من التوقيع الثنائي الفعلي للملفات حتى ٢٥ ميجابايت (صور، PDF بما يشمل BOM، صوت، DOCX/PPTX/XLSX) عبر أجزاء محققة الطول والبصمة، مع روابط وصول قصيرة الأجل.
- **study_reminders / subject_alert_prefs / study_challenges / study_challenge_logs / majalis_rooms**: التذكيرات، نغمات وألوان المواد، تحديات المذاكرة، سجل أوقات الذروة، وغرف مجالس المذاكرة الجماعية.
- **app_settings / admin_audits**: إعدادات الهوية ومجلس المذاكرة وإعدادات الجروب وسجل التدقيق الإداري.

## ٣. قواعد الأدوار والصلاحيات

- **العضو (member)**: تصفح المواد، المشاركة في قناتي `أسئلة` و`عام` عند فتح المحادثة (ما لم يكن مكتومًا)، قراءة `إعلانات` فقط، حذف رسائله عند الكل خلال ٤٨ ساعة فقط، وتخصيص إعدادات محادثته الشخصية.
- **المشرف (admin)**: كل صلاحيات العضو + نشر الإعلانات، قفل/فتح المحادثة، تثبيت الرسائل في القنوات، كتم الأعضاء العاديين في المحادثة، قبول/رفض طلبات الانضمام وطلبات الرسائل القديمة، إدارة المواد والأقسام، ترقية/خفض الأعضاء غير المالك، وتعديل معلومات الجروب إذا سمحت السياسة. لا يمكنه المساس بالمالك أو إزالة مشرف آخر.
- **المالك (owner)**: حساب محمي لا يمكن حذفه أو تغييره أو إعادة تعيين كلمة مروره من أي حساب آخر، ويمتلك وحدَه صلاحية حذف أي رسالة عند الجميع في أي وقت دون قيد ٤٨ ساعة، والمحو الكامل لرسالة مفردة أو لقناة كاملة أو لجميع المحادثات من قاعدة البيانات، وإزالة المشرفين أو كتمهم، وتصدير أرشيف الكود المنقّى.

## ٤. الرفع على GitHub (Open Source)

المشروع مرخص برخصة **MIT** (`LICENSE`). للرفع على مستودع GitHub جديد بعد التأكد من عدم وجود ملفات `.env` أو قواعد بيانات محلية متتبعة:

```bash
git init
git add .
git commit -m "Initial open-source release of Rahhala"
git branch -M main
git remote add origin https://github.com/<USERNAME>/<REPO>.git
git push -u origin main
```
